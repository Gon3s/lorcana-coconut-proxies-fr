# Revue initiale avant fusion

Le CSV initial contient 27 effets EN transcrits à partir des JPEG Coconut avec aide de l'OCR et correction des symboles visibles ; les effets FR proviennent d'une traduction de travail. Une personne doit relire **les 27 lignes** avec les images détaillées avant de fusionner la branche sur `main`.

Points de contrôle ciblés :

| Carte | À vérifier |
| --- | --- |
| `coconut-007` Mufasa | L'image Coconut verrouillée dit **2** cartes dans la réserve, alors que le PDF bêta antérieur en dit 3. |
| `coconut-027` Le Chaudron magique | Le nom de l'objet dans l'effet FR est celui du catalogue officiel ; contrôler que c'est bien l'association voulue. |
| `coconut-008` Nick Wilde | `Pawpsicle` a été traduit par **Glace à l'eau**, nom de l'objet dans le catalogue FR. |
| `coconut-009` Blanche-Neige | Relire la condition de sept cartes Personnage Sept Nains de noms différents et la portée des zones main/défausse/jeu. |
| `coconut-010` Donald | Confirmer la terminologie française de **Boost** et les objets des réductions. |
| `coconut-018` Dumbo | Le symbole EN est `{exert}` ; confirmer la formulation FR « symbole d'inclinaison ». |
| `coconut-011`, `coconut-016` | Les symboles EN sont `{strength}` ; la traduction utilise « Force ». |

Contrôler également que le titre/sous-titre FR de chaque ligne correspond à la carte standard associée, que le texte tient dans les zones peintes, que l'illustration montre la même scène, que les crédits et symboles d'encre restent visibles et que les trois planches A4 ont l'écart imprimé prévu.
